# Flowrly

Tauri 2 + React 19 desktop app (macOS only). Time tracking for freelancers, invoicing via Fakturoid, focused-window activity tracking summarised by an LLM. Domain vocabulary lives in `CONTEXT.md`; read it before naming things.

## Commands

```sh
pnpm tauri dev            # run app (regenerates src/bindings.ts on start)
pnpm exec tsc --noEmit    # type-check frontend
pnpm exec vite build      # bundle frontend
cd src-tauri && cargo test   # Rust unit tests; also re-exports src/bindings.ts
```

## Layout

- `src-tauri/src/` Rust owns all data and logic. `commands.rs` is the only Tauri surface; `repo.rs` SQL; `activity.rs` sample aggregation; `ai.rs` rig-based extraction; `fakturoid.rs` API client; `invoice.rs` pure invoice math; `backup.rs` VACUUM INTO snapshots; `i18n.rs` language resolution for menus, errors and AI prompts; `tracker.rs` polling thread.
- `src/bindings.ts` is generated by tauri-specta. Never edit by hand.
- `src/routes/*` one file per screen; `src/routes/onboarding.tsx` first-run wizard (chosen over the app shell by `src/components/root.tsx`), its animated demos in `src/components/onboarding/*`; `src/components/entry-form.tsx` shared create/edit form; `src/lib/api.ts` TanStack Query hooks; `src/i18n/` i18next setup and locale files; `src/styles/globals.css` design tokens.

## Gotchas

- `tauri-specta` / `specta` must stay on the `2.0.0-rc.*` line (pinned with `=`); the `1.x` "stable" releases target Tauri 1 and break dependency resolution.
- `rusqlite_migration` is pinned `~2.5` because 2.6 needs rustc 1.95; keep `rusqlite` on the version it requires (0.39).
- specta-typescript forbids `i64`; models use `i32`. `f64` exports as `number | null`, so the frontend does `?? 0`.
- Settings are stored as one JSON blob; new fields need a default in `Settings::default()` and are merged over defaults on load.
- `Settings.onboarding_completed` gates consent: until the wizard sets it, nothing is tracked and launch-at-login is not registered (`Settings::tracking_active`, `apply_settings`). Migration 0005 sets it for installs that already had a client. The wizard can be replayed from Settings (`/welcome`) without clearing the flag.
- Onboarding copy promises that data stays local and that only the opt-in Fakturoid and AI calls go online. Keep that true: no telemetry, updater pings or other background network use without changing that copy.
- Window titles come from the Accessibility API (`AXFocusedWindow` → `AXTitle`, see `tracker.rs`) and need the macOS Accessibility permission; the tracker prompts for it on start. `active-win-pos-rs` is kept only for the frontmost app name/pid — its `kCGWindowName` is the first CG window of the pid, which is the tab bar or a stale tab for tabbed apps like Ghostty.
- `tools/winprobe` dumps everything macOS reports about an app's windows (CG list + AX tree); use it to troubleshoot tracking.
- Fakturoid has no "invoice from generator" endpoint in v3; we copy generator fields client-side (`invoice.rs`).
- Theme follows the OS only (`prefers-color-scheme`); there is no theme switcher.
- UI ships in English, German and Czech. Frontend strings live in `src/i18n/locales/{en,de,cs}/<namespace>.ts` (i18next, keys typed from `en`; de/cs `satisfies Translation<typeof en>`, so a missing key fails `tsc`). Czech plurals need `_one`/`_few`/`_many`/`_other`. Never hard-code user-facing text, date-fns patterns or number formats: use `t()` and the helpers in `src/lib/format.ts`.
- Rust-side text (native menu, tray, error messages) lives in `src-tauri/locales/app.yml` (rust-i18n, one file, all three languages per key; `i18n::tests` fails when one is missing). `Settings.language` is `""` to follow the OS (resolved in Rust via `sys-locale`, exposed as `systemLanguage`); `apply_settings` switches the Rust locale and rebuilds the menus. `Settings.ai_language` (`""` = UI language) sets the language the LLM writes day summaries and suggestions in.
- Adding a language: a folder in `src/i18n/locales`, entries in `LANGUAGES` / date-fns and Intl maps in `src/i18n/index.ts`, `i18n::SUPPORTED` and `language_name` in Rust, every key in `app.yml`, and `CFBundleLocalizations` in `src-tauri/Info.plist`.
